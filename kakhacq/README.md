# ক, খ, CQ — ফাইল আপলোড ফিচার

এই ফোল্ডারে ক/খ/CQ-এর জন্য mhtml/html ফাইল আপলোড করে স্বয়ংক্রিয়
পার্স ও প্রিমিয়াম UI-তে দেখানোর সম্পূর্ণ ফিচার আছে। **এই ফিচারের
কোনো কোড repo-র বাকি কোনো ফাইলে নেই** — শুধু `admin.html` ও
`exam.html`-এ কয়েকটা `<script src="kakhacq/...">` লাইন যোগ করা
হয়েছে, যাতে এই ফাইলগুলো লোড হয়।

## ফাইল গঠন

| ফাইল | কাজ |
|---|---|
| `kakhacq-parser.js` | mhtml/html ফাইল থেকে প্রশ্ন/উত্তর/ছবি বের করে (ক, খ, CQ — ৩ ধরনের ফরম্যাটের জন্য আলাদা পার্সার) |
| `imgbb-manager.js` | একাধিক ImgBB key থেকে অটো-রোটেশন করে ছবি আপলোড, quota শেষ হলে পরের key, এরর হলে admin নোটিফাই |
| `kakhacq-admin.js` | অ্যাডমিন প্যানেলে ফাইল-আপলোড UI বসায়, পার্স+আপলোড+সেইভ ফ্লো চালায় |
| `kakhacq-user-render.js` | ইউজার সাইডে প্রিমিয়াম কার্ড UI দেখায় (অ্যাকর্ডিয়ন, পেজিনেশন, অ্যানিমেশন) |
| `imgbb-config.template.js` | ImgBB key বসানোর টেমপ্লেট |
| `supabase-migration.sql` | Supabase-এ নতুন কলাম যোগ করার SQL |

## সেটআপ (পুশ করার পর করণীয়)

### ১. Supabase মাইগ্রেশন রান করো
Supabase Dashboard → SQL Editor → `supabase-migration.sql`-এর কনটেন্ট পেস্ট করে রান করো।
এটা `ka_kha_cq` টেবিলে `parsed_content` (JSONB) কলাম যোগ করবে। বিদ্যমান কোনো ডেটা মুছবে না।

### ২. ImgBB key বসাও (ঐচ্ছিক কিন্তু রেকমেন্ডেড)
1. `imgbb-config.template.js` ফাইলটা কপি করে নাম দাও `imgbb-config.js`
2. নিজের ImgBB API key গুলো অ্যারেতে বসাও
3. এই ফাইল **`.gitignore`-এ আছে** — কখনো GitHub-এ পুশ হবে না, শুধু সার্ভারে থাকবে
4. key না থাকলেও ফিচার কাজ করবে — শুধু ছবি ImgBB-তে re-host হবে না, original লিংক থেকেই দেখাবে

⚠️ **কখনো আসল ImgBB key চ্যাটে বা কোনো পাবলিক জায়গায় পেস্ট কোরো না।**
যদি কোনো key আগে কোথাও শেয়ার হয়ে থাকে, ImgBB ড্যাশবোর্ড থেকে সেটা
রিজেনারেট/রিভোক করে নতুন key ব্যবহার করো।

## কীভাবে কাজ করে

1. **অ্যাডমিন** ক,খ,CQ ট্যাবে গিয়ে সাবজেক্ট/চ্যাপ্টার পূরণ করে, টাইপ সিলেক্ট করে, তারপর mhtml/html ফাইল আপলোড করে
2. ফাইল ক্লায়েন্ট-সাইডে পার্স হয় (ব্রাউজারেই, কোনো সার্ভার লাগে না)
3. প্রশ্ন/উত্তরের মধ্যে থাকা ছবিগুলো ImgBB-তে re-upload হয় (কনফিগার করা থাকলে)
4. পুরো স্ট্রাকচার্ড ডেটা Supabase-এর `ka_kha_cq` টেবিলে `parsed_content` কলামে JSON হিসেবে সেইভ হয়
5. **ইউজার** এক্সাম পেজে ক/খ/CQ ক্লিক করলে — যদি `parsed_content` থাকে, প্রিমিয়াম কার্ড UI-তে দেখায় (নতুন ট্যাবে যায় না)
6. পুরনো লিংক-বেইজড এন্ট্রি (যেগুলোতে `parsed_content` নেই) আগের মতোই কাজ করে — কিছু ভাঙেনি

## টেস্টিং নোট

৩টা স্যাম্পল ফাইল (ক, খ, CQ ফরম্যাট) দিয়ে পার্সার টেস্ট করা হয়েছে —
প্রতিটায় ২৫টি আইটেম সঠিকভাবে বের হয়েছে, ছবি প্লেসহোল্ডার ঠিকমতো
রিজলভ হয়েছে, এবং কোনো leftover `{{IMG_n}}` থাকেনি।

## আপডেট: "সেইভ হয় কিন্তু লিস্টে/ইউজার সাইডে দেখায় না" — বাগ ফিক্স

এই সমস্যার দুটো মূল কারণ পাওয়া গেছে এবং ফিক্স করা হয়েছে:

1. **অ্যাডমিন তালিকা** — আপলোডের পর `loadKaKha()` কল হতো, কিন্তু "তালিকা"
   সেকশনের ফিল্টার ড্রপডাউন (`kaFilterType`) আগে থেকে অন্য টাইপে (যেমন `kha`)
   সেট থাকলে নতুন `ka` এন্ট্রি ফিল্টার হয়ে বাদ পড়ে যেত। এখন আপলোড সফল হলে
   ফিল্টার অটোমেটিক সেই টাইপে সেট হয়ে যায়।
2. **ইউজার সাইড** — `loadKaKhaContent` override শুধু *প্রথম* parsed_content
   এন্ট্রিকে সরাসরি দেখিয়ে দিত; একই টাইপে একাধিক সাবজেক্ট/চ্যাপ্টার থাকলে
   বাকিগুলো (এমনকি অন্য ফাইল-আপলোড এন্ট্রিও) আর কখনো দেখা যেত না। এখন
   একাধিক এন্ট্রি থাকলে প্রথমে চ্যাপ্টার-তালিকা দেখানো হয়, ক্লিক করলে
   নির্দিষ্ট এন্ট্রির প্রিমিয়াম কার্ড UI খোলে (ফিরে যাওয়ার বাটন সহ)।

এছাড়া `saveToSupabase`-এ insert response যাচাই করা হচ্ছে — যদি Supabase
RLS পলিসি বা মিসিং কলামের কারণে silently row সেইভ না হয়, এখন স্পষ্ট এরর
মেসেজ দেখাবে।

**যদি এর পরেও সমস্যা থাকে**, প্রথমে নিশ্চিত করুন:
- `supabase-migration.sql` Supabase SQL Editor-এ রান হয়েছে (`parsed_content` কলাম আছে কিনা)
- `ka_kha_cq` টেবিলে RLS policy public insert/select অনুমতি দেয় কিনা
- ব্রাউজার Console (F12) এ কোনো red error আসছে কিনা — থাকলে exact মেসেজ দেখুন
